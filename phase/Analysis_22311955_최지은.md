## 1. Introduce
**1) Project background**
대학 생활은 끊임없는 학업의 연속이다. 학생들은 매 학기 수많은 과제(Assignment)와 시험(Exam)에 직면하며, 각 항목은 저마다의 마감 기한, 세부 수행 단계, 시험 범위, 그리고 준비 상태를 가지고 있다. 단순히 "무엇을 해야 한다"는 사실을 아는 것보다 중요한 것은, **"현재 어느 정도 진행되었는가(Progress)"**와 **"시험을 위해 무엇이 남았는가(Checklist)"**를 정확히 파악하는 것이다.

기존의 일반적인 To-Do 리스트 앱들은 이러한 학업 특화적 요구사항을 충족시키지 못한다. 과제의 경우 단순히 '완료/미완료'로만 나뉘어 세부적인 진행 과정을 추적하기 어렵고, 시험의 경우 단순한 날짜 기록 외에 '회독 수'나 '시험 범위'와 같은 학습 맥락을 담아내지 못한다. 이러한 정보의 파편화는 학생들로 하여금 마감 직전의 급박한 상황을 초래하거나, 시험 준비 과정에서 불필요한 불안감을 느끼게 만드는 원인이 된다.

'StudyMate'는 이러한 문제점을 해결하기 위해 탄생했다. 본 소프트웨어는 과제의 세부 할 일(Task)을 기반으로 한 **실시간 진행도 시각화**와, 시험 준비의 단계별 체크리스트를 통한 **체계적 학습 관리**를 핵심 가치로 삼는다. 또한, 학습 흐름을 방해하지 않으면서도 핵심 정보를 상시 확인할 수 있는 **미니 위젯(Mini-Widget)** 기능을 제공하여, 사용자가 별도의 조작 없이도 자신의 학습 페이스를 유지할 수 있도록 돕는다. 즉, StudyMate는 단순한 기록 도구가 아니라 학생의 학습 사이클을 함께 관리하는 스마트한 파트너를 지향한다.

### 1.2. Goal
- **학습 데이터의 입체적 관리:** 과제의 진행률(%)과 시험의 준비 단계(회독 등)를 데이터화하여 정량적인 학습 상태 파악을 가능하게 한다.
- **시각적 인지 극대화:** 프로그레스 바, D-Day 배지, 테마별 컬러 코딩을 통해 사용자가 직관적으로 마감 임박 사항을 인지하도록 한다.
- **학습 연속성 보장:** 미니 위젯을 통해 메인 작업 중에도 학습 현황을 상시 모니터링할 수 있는 환경을 구축한다.
- **심미적/기능적 사용자 경험 제공:** 테마 커스텀 및 SVG 아이콘 기반의 현대적인 UI를 통해 학습 동기를 부여하는 쾌적한 환경을 제공한다.

## 시험공부 관리
<img width="1119" height="789" alt="image" src="https://github.com/user-attachments/assets/0319ac0c-06bb-46cd-9033-2cea92b19825" /><br>

시험은 체크리스트를 모두 체크해도 완료 버튼이 팝업되지 않으며, 수동으로 박스 우클릭/우상단에서 삭제 버튼을 누를 경우 '휴지통'으로 이동된다.

위젯은 모든 프로그램의 가장 위에 위치하며, 위치를 옮길 수 있다. 제공되는 기능은 타이머와 각 과제/시험 탭의 일정을 확인하는 기능이 있다.<br>


<img width="320" height="246" alt="image" src="https://github.com/user-attachments/assets/714a199f-0ebf-4f11-aa55-9cc9644b1afa" /><br>
과제 목록 혹은 시험공부 관리 탭에서 과제/시험을 추가할 시, 곧바로 미니 위젯에 반영된다. 과제/시험은 미니 위젯에서 번갈아가며 확인할 수 있다.<br>

<img width="639" height="246" alt="image" src="https://github.com/user-attachments/assets/90227693-1e4f-4c6f-8fd8-692aefa72953" /><br>
목록에서 요소를 클릭할 경우, 메인 탭에서 추가했던 체크리스트가 팝업된다. 해당 체크리스트에 체크하면 메인 탭에도 곧바로 반영되며, 이를 통해 유동적으로 할 일을 관리할 수 있다.<br>

## 5. Glossary
- StudyMate: 과제 진행도와 시험 준비 상태를 통합 관리하는 본 소프트웨어의 명칭이다.
- Assignment (과제): 마감 기한과 세부 할 일(Task) 목록을 가진 학습 단위이다.
- Exam (시험): 과목, 날짜, 장소, 범위 및 체크리스트를 포함하는 학습 단위이다.
- Task (할 일): 과제를 구성하는 최소 단위의 행동 항목이며, 완료 여부에 따라 과제의 진행률을 결정한다.
- Mini-Widget (미니 위젯): 메인 창과 별개로 항상 최상단(Always on Top)에 위치하여 핵심 정보를 요약 제공하는 보조 UI이다.
- Progress Bar (진행도 바): 과제의 전체 Task 중 완료된 Task의 비율을 시각적으로 나타낸 요소이다.
- D-Day: 시험 날짜와 현재 날짜를 비교하여 남은 기간을 나타내는 지표이다.
- Theme (테마): UI의 배경색, 카드색, 강조색(Primary), 텍스트색 등을 정의한 색상 집합이다.
- Rebuild / Refresh: 데이터의 변경 사항을 UI에 즉각 반영하기 위해 위젯을 삭제하고 다시 그리는 프로세스이다.
- Trash (휴지통): 사용자가 삭제한 과제나 시험 항목이 임시로 보관되는 영역이다.
- Subject (과목): 과제나 시험이 속한 학문적 분류이며, 고유 색상을 부여하는 기준으로 사용된다.
