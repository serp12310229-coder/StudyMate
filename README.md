<p align="center">대학생을 위한 과제/시험공부 관리 데스크톱 앱</p>

## 주요 기능
- **과제 관리**: 과제 추가 및 수정, 체크리스트를 통해 과제 현황을 관리할 수 있습니다.
- **시험 관리**: 시험 추가 및 수정, 기본 1~2회독 + 다회독, 이외 체크리스트 추가를 통해 시험 관련 항목을 관리할 수 있습니다.
- **최상단 미니 위젯**: 타이머 기능, 과제/시험의 체크리스트를 실시간으로 관리할 수 있습니다.
  위치 변경이 가능하며, 위치를 고정할 수 있습니다.
- **백그라운드 실행**: 메인 탭을 닫아도 완전히 종료되지 않으며, 백그라운드에서 계속 실행됩니다.
  작업표시줄의 숨겨진 아이콘 표시 목록(트레이)에서 종료 및 설정이 가능합니다.
- **휴지통**: 삭제/완료된 과제와 시험을 휴지통에서 확인하고, 영구 삭제할 수 있습니다.
- **자유로운 색상 커스텀**: 상단 설정을 통해 전체적인 ui의 색상 변경이 가능하며, 각 과제/시험의 좌측 점을 클릭하여 개별 항목의 색상을 조정할 수 있습니다.

## 실행
1. 실행 파일 다운로드
추후 Release에서 exe 파일 추가 예정

2. 소스에서 실행
```
pip install PyQt5
cd StudyMate
python main.py
```

## 데이터
~/.studymate.json 에 자동 저장됩니다.
모든 정보는 Local에 저장됩니다.
