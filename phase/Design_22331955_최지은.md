# [Design] StudyMate

**StudyMate — 대학생 학습 효율 극대화를 위한 과제 및 시험 통합 관리 시스템**

---

## 1. Introduction
지난 analysis 문서에서 usecase diagram을 통해 기본적인 흐름을 이해하고 코드를 구조화하였다.
이어, 본 보고서에서는 analysis 과정을 거친 후 구조화한 class diagram을 그리고 class diagram description을 구체적으로 작성하였다.
현재 토대가 되는 코드는 대부분 완성되었으며 일부 기능 구현과 디버깅 과정이 남아있기 때문에, 해당 지점을 해결한 뒤 모든 과정을 완료할 수 있을 것으로 판단된다.

## 3. Class diagram description

### 1. MainWindow
main applicaion 창을 관리하는 핵심 클래스로, PyQt5 기반의 UI를 제공한다. 과제/시험/휴지통 탭을 통합 관리한다.

#### Attributes

| Name | Type | Scope | Description |
|---|---|---|---|
| data | dict | private | 과제, 시험, 설정 등 전체 애플리케이션 데이터 |
| mini_win | MiniWidget | private | 미니 위젯 인스턴스 참조 |
| _tab_btns | dict | private | 탭 버튼 딕셔너리 (key: 탭 이름, value: QPushButton) |
| _stack | QStackedWidget | private | 탭 컨텐츠를 표시하는 스택 위젯 |
| _atab | AssignmentTab | private | 과제 탭 인스턴스 |
| _etab | ExamTab | private | 시험 탭 인스턴스 |
| _ttab | TrashTab | private | 휴지통 탭 인스턴스 |
| _top_tg | ToggleSwitch | private | 최상단 고정 토글 스위치 |


#### Operations

| Name | Arguments | Return | Description |
|---|---|---|---|
| __init__ | data:dict, mini_win:MiniWidget | void | 생성자. 데이터와 미니위젯 참조를 초기화 |
| _build |  | void | UI 구성요소를 생성 및 배치 |
| _upd_tabs | active:str | void | 활성 탭 버튼의 스타일 업데이트 |
| _switch | key:str | void | 탭 전환 (assignment/exam/trash) |
| _toggle_top | checked:bool | void | 최상단 고정 토글 처리 |
| _apply_top | on:bool | void | WindowStaysOnTopHint 플래그 적용 |
| _open_settings |  | void | 설정 다이얼로그 열기 |
| _on_theme_changed |  | void | 테마 변경 시 전체 UI 재구성 |
| _on_data_changed |  | void | 데이터 변경 시 탭 및 미니위젯 새로고침 |
| _save |  | void | 데이터를 파일에 저장 |
| closeEvent | e:QCloseEvent | void | 창 닫기 이벤트 처리 (트레이로 숨김) |


### 2. MiniWidget
'최상단에 표시'를 토글하면 항상 화면에 표시되는 미니 위젯이다. 타이머, 과제/시험의 요약 정보를 제공하며, 드래그를 통한 위치 이동이 가능하다.

#### Attributes

| Name | Type | Scope | Description |
|---|---|---|---|
| data | dict | private | 애플리케이션 데이터 참조 |
| on_save | callable | private | 데이터 저장 콜백 함수 |
| _locked | bool | private | 위치 잠금 상태 |
| _drag_pos | QPoint | private | 드래그 시작 위치 |
| _cur_tab | str | private | 현재 선택된 탭 (assignment/exam) |
| _popup | ChecklistPopup | private | 체크리스트 팝업 인스턴스 |
| _cmap | dict | private | 과목별 색상 매핑 |
| _elapsed | int | private | 경과 시간 (초) |
| _running | bool | private | 타이머 실행 상태 |
| _timer | QTimer | private | 1초 간격 타이머 |
| _inact | QTimer | private | 비활성 감지 타이머 (60초) |


#### Operations

| Name | Arguments | Return | Description |
|---|---|---|---|
| __init__ | data:dict, on_save:callable | void | 생성자. 데이터 및 저장 콜백 초기화 |
| _build |  | void | 미니 위젯 UI 구성 |
| _switch_tab | key:str | void | 탭 전환 및 목록 새로고침 |
| _refresh_list |  | void | 과제/시험 목록 재렌더링 |
| _show_popup | e, item_data, itype, color | void | 체크리스트 팝업 표시 |
| set_always_on_top | on:bool | void | 항상 위 설정 적용 |
| _tick |  | void | 타이머 1초 증가 |

| _stop |  | void | 타이머 중단 및 초기화 |
| reset_inactivity |  | void | 비활성 타이머 리셋 |

| mouseMoveEvent | e:QMouseEvent | void | 위젯 위치 이동 |
| mouseReleaseEvent | e:QMouseEvent | void | 위치 저장 |

github 환경에서 mermaid로 표현하기 때문에, 지원 한계 탓에 일부 간편화한 구간이 있다.

### Use Case 1: 애플리케이션 초기화 및 시작

```mermaid
sequenceDiagram

    Main->>MiniWidget: __init__(data, on_save)
    activate MiniWidget
    MiniWidget->>MiniWidget: _build()
    MiniWidget-->>Main:

프로그램 실행부터 메인 창 표시까지의 전체 초기화 프로세스로, 사용자가 main.py를 실행했음/시스템에 저장된 data.json 파일이 존재함(혹은 신규 생성됨)이 시작 조건으로 지정된다.<br>
**실행 흐름**
1. main() 함수 실행
   - QApplication 인스턴스 생성
   - core.data.load()로 저장된 데이터 로드
   - setup_font()로 Pretendard 폰트 등록
   - apply_theme()로 저장된 테마 적용
2. MiniWidget 생성
   - __init__(data, on_save) 호출
   - _build()로 UI 구성 (타이머, 탭, 리스트)
3. MainWindow 생성
   - __init__(data, mini_win) 호출
   - _build()로 헤더, 탭바, 컨텐츠 영역 구성
   - 각 탭 (AssignmentTab, ExamTab, TrashTab) 생성
   - 각 탭의 _build()로 카드 목록 렌더링
4. TrayIcon 생성
   - 시스템 트레이에 아이콘 표시
   - 메뉴 (메인 창 열기, 미니 위젯 토글, 종료) 설정
5. 창 표시
   - MainWindow.show() 호출
   - always_on_top 설정 시 MiniWidget.show() 호출
   - app.exec_()로 이벤트 루프 시작
**종료 조건**
- 메인 창과 미니 위젯이 사용자에게 표시됨
- 이벤트 루프가 실행되어 사용자 입력 대기 상태
**주요 특징**
- 모든 탭이 초기화 시점에 한 번에 생성됨 (Lazy Loading 없음)
- MiniWidget은 MainWindow보다 먼저 생성 (참조 전달 목적)

사용자가 새 과제를 추가하는 전체 프로세스로, 메인 창의 '과제 관리 탭'이 활성화 되었으며 사용자가 '새 과제' 버튼을 클릭한 것이 시작 조건이다.<br>
**실행 흐름**
1. 다이얼로그 생성 및 표시
   - AssignmentTab._add() 메서드 호출
   - AddAssignmentDialog.__init__(parent=self) 생성
   - _build()로 폼 UI 구성 (과제명, 과목, 마감일, 할일)
   - ChecklistEditor 인스턴스 생성 및 초기 빈 행 추가
2. 사용자 입력
   - 과제명 입력 → Enter → 과목명 필드로 포커스 이동
   - 과목명 입력 → Enter → 마감일 버튼으로 포커스 이동
   - 마감일 버튼 클릭/Enter → CalendarDialog 표시
   - 날짜 및 시간 선택 → result_dt 반환
   - 할일 에디터로 포커스 자동 이동 (_focus_task_editor)
3. 할일 목록 입력
   - ChecklistEditor에서 첫 번째 할일 입력
   - Enter 키 시 _on_enter() 호출 → 다음 행 자동 추가
   - 반복하여 여러 할일 추가 가능
4. 데이터 검증 및 저장
   - "추가하기" 버튼 클릭 → _submit() 호출
   - 필수 필드 검증 (과제명, 과목명)
   - 누락 시 경고 메시지, 완료 시 result_data 생성
5. UI 업데이트
   - data["assignments"].append(result_data)
   - AssignmentTab._rebuild() 호출
   - 새 AssignmentCard 생성 및 _populate()
   - refreshed 시그널 발생 → MainWindow로 전파
<br>**종료 조건**
• 새 과제 카드가 과제 탭에 표시됨
• 데이터가 파일에 저장됨
• 미니 위젯의 과제 목록도 업데이트됨
<br>**대안 흐름**
• 필수 필드 누락 시: 경고 다이얼로그 표시 후 입력 화면 유지
• 사용자 취소 시: 다이얼로그 닫히고 데이터 변경 없음

    Confirm->>User: 확인 다이얼로그 표시
    Note over Confirm: "휴지통의 모든 항목을<br/>영구 삭제할까요?<br/>되돌릴 수 없습니다."

    User->>Confirm: "전체 삭제" 버튼 클릭

    alt 사용자 확인
        Confirm->>Confirm: accept()
        Confirm-->>TrashTab: Accepted
        deactivate Confirm

        TrashTab->>Data: data["deleted"] = []
        TrashTab->>TrashTab: on_save()
        TrashTab->>TrashTab: _rebuild()

        TrashTab->>TrashTab: _build()
        Note over TrashTab: 빈 휴지통 UI<br/>"휴지통이 비어있어요 🗑"

        TrashTab->>TrashTab: refreshed 시그널
        TrashTab->>User: 빈 휴지통 표시

    else 사용자 취소
        Confirm->>Confirm: reject()
        Confirm-->>TrashTab: Rejected
        deactivate Confirm
    end

    deactivate TrashTab
```
- "전체 삭제" 버튼 클릭 → ConfirmDialog
- 확인 시: data["deleted"] = []
- on_save() → 파일 저장
- _rebuild() → 빈 휴지통 UI 표시

## 6. Glossary
- StudyMate: 과제 진행도와 시험 준비 상태를 통합 관리하는 본 소프트웨어의 명칭이다.
- Assignment (과제): 마감 기한과 세부 할 일(Task) 목록을 가진 학습 단위이다.
- Exam (시험): 과목, 날짜, 장소, 범위 및 체크리스트를 포함하는 학습 단위이다.
- Task (할 일): 과제를 구성하는 최소 단위의 행동 항목이며, 완료 여부에 따라 과제의 진행률을 결정한다.
- Mini-Widget (미니 위젯): 메인 창과 별개로 항상 최상단(Always on Top)에 위치하여 핵심 정보를 요약 제공하는 보조 UI이다.
- Progress Bar (진행도 바): 과제의 전체 Task 중 완료된 Task의 비율을 시각적으로 나타낸 요소이다.
- D-Day: 시험 날짜와 현재 날짜를 비교하여 남은 기간을 나타내는 지표이다.
- Theme (테마): UI의 배경색, 카드색, 강조색(Primary), 텍스트색 등을 정의한 색상 집합이다.
- Rebuild / Refresh: 데이터의 변경 사항을 UI에 즉각 반영하기 위해 위젯을 삭제하고 다시 그리는 프로세스이다.
- Trash (휴지통): 사용자가 삭제한 과제나 시험 항목이 임시로 보관되는 영역이다.
- Subject (과목): 과제나 시험이 속한 학문적 분류이며, 고유 색상을 부여하는 기준으로 사용된다.
